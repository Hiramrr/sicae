# Contratos de integracion

Guarden aqui los contratos formales de comunicacion entre microservicios.

Carpetas sugeridas:

- `soap/`: WSDL o documentacion del contrato SOAP.
- `grpc/`: archivos `.proto`.
- `rpc/`: contratos o descripcion de RPC si el equipo decide usar RPC no-gRPC.

La API publica que se prueba con Postman sigue documentada en `docs/API_CONTRATOS.md`.
