# Scripts PostgreSQL - dominio usuarios

Coloquen aqui los scripts entregados por el profesor para:

- usuarios;
- roles;
- tipos de usuario;
- programas educativos.

Recomendacion de nombres:

```text
001_schema.sql
002_seed.sql
```

PostgreSQL ejecuta los archivos de esta carpeta solo cuando el volumen se crea por primera vez. Para reiniciar desde cero:

```bash
make reset-db
make up-db
```
